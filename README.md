# WhoFundsOSS

Public record of who funds open source. Amounts are a floor, read once a month.

This branch is the TanStack Start build (ranking, movements, mysteries, graph, watchlist, method, internal API). The product spec stays in `docs/`.

```bash
npm install
npm run dev
```
